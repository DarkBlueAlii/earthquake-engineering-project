# Earthquake Engineering — MEng Coursework (CIVL 8360)

Coursework files from CIVL 8360 (Earthquake Engineering / Structural Dynamics), MEng in Civil Engineering, University of Windsor (2025–2026).

## Contents

- **MATLAB scripts** (`.m`) — structural dynamics computations: response spectrum analysis, ground-motion record processing and selection, peak-value extraction and data reduction
- **Spreadsheets** (`.xlsx`) — assignment calculations, response spectrum plots, peak and reduction tables
- **Ground-motion record** (`M7_soil_FN_9.acc`) — acceleration time history used in the analyses
- **Reports and presentations** — term project report (PDF) and task deliverables (PDF, PPTX)
- **Project schedule** (`Gantt Chart - All tasks.mpp`) — MS Project schedule of the coursework tasks

## Tools
